# 2026-10-26 施工说明（第二轮）

对应提交：`bcc2b56`（`main`）。上一轮基线：`87b4fda`。

## 做了什么

| 用户要求 | 根因 | 改动 |
|---|---|---|
| 宠物一直“睡着啦”，不跟 WorkBuddy | `auto` 只在守护进程启动那一刻选源，选中 Codex 后不再重算 | 新增 `AutoSource`：每次 `/state` 同时取 WorkBuddy 与 Codex，按“谁在干活 → 谁最后动过 → 状态语义”排序，同分 WorkBuddy 优先 |
| 卡片不刷新，“假卡片” | 每次统计要全量重扫日志（约 3.5 秒），服务端只能缓存 20 秒 | 按文件 `mtime + size` 增量解析（命中约 20ms）；TTL 20s → 3s；前端状态 2s、用量 3s；启动后台预热 |
| 已花费永远是 `—` | 只认中转站导出账单，本机从未导入 | 改为 Claude Code 本机日志 × 模型单价（读 `~/.cc-switch/model-pricing.json`），与 CC Switch 面板同口径；有核对过的账单时仍以账单为准 |
| 删除“睡着啦”状态标签 | 文字标签与角色动画重复，且容易被误读 | 删除 `#petTaskState`；任务状态只由动画表达。头部的“N 项任务”同样删除，卡片只留已花费与今日 Token |
| 已花费换配色 | 近黑实块与角色不搭 | 暖白底 + 深蓝字（取自立绘），保留实底和描边保证可读 |
| 不显示更新时间 | 用户只要自动刷新 | 删除时间戳与小圆点；保留 2s/3s 轮询 |

## 遗留 / 限制

- 已花费是按模型单价**折算**，不是中转站实际扣费；WorkBuddy / Codex 走订阅，不计金额。
- 只看本机可读日志；不等于账户全部设备用量。
- 费用价目表依赖 `~/.cc-switch/model-pricing.json`；文件不存在时用 `claude_cost.py` 内置的 Claude 价目兜底。
