# run 素材：给「高级模型定稿」的规格

日期：2026-09-23 21:0x　｜　背景：用户问"素材问题还是机制问题"，并愿意找高级模型定稿

---

## 一、先把责任分清楚

| 现象                               | 归属                        | 状态                   |
| -------------------------------- | ------------------------- | -------------------- |
| 腿的切断边露在裙子外面（"腿挂在裙子外"）            | **我的机制**：贴图顺序错了（先把腿画在身体上） | 已定位；修法"先腿后身"可行，但会遮住腿 |
| **裙摆太长，只露出约 55px 的腿 → 跑步动作读不出来** | **素材（角色设计）**              | 需要定稿解决               |
| 角色的白裙子与背景同色，永远抠不干净               | **素材**（生成时若给纯色背景就没这问题）    | 已有灌水法兜住              |
| 两条腿完全一样、没有前后明暗区分 → "换腿"看不出来      | **素材（角色设计）**              | 见下方要求                |
| 头顶呆毛/尾巴动起来就穿帮                    | 机制（次级运动没做）                | 未做                   |

**一句话**：**能修的我修掉了；剩下的要动角色设计本身，那是素材层面的事。**

---

## 二、核心结论：现在这套图**做不出合格的跑步**

AI 逐帧生成的「整只角色平面图」有两个天生缺陷，这次全部撞上了：

1. **没有图层** → 想做"身体固定、只有腿动"就必须把平面图切开，  
   切开必然在裙摆处留下接缝（我把腿画在身体上面 → 接缝露出；画在下面 → 腿被盖光）。
2. **两条腿没有任何区分**（同色同款、无前后明暗）→  
   "右腿在前"和"左腿在前"在侧面视角下**是同一张图**，交替根本无法被眼睛读出来。

再加上角色本身**裙子长到膝盖以下**，大腿完全被遮住，  
露出来的腿只有 55px 左右 —— 跑步动作只剩这么窄一条带来表现。

**所以：继续在"平面整图"这条路上加大生成量，不会有质变。**

## 三、要什么素材

### 方案 A（**最推荐**）：分层部件包

一套 PNG 图层，**同一坐标系、同一画布尺寸、透明背景**，每个部件一张图：

| 图层文件                                        | 内容                                 | 用途              |
| ------------------------------------------- | ---------------------------------- | --------------- |
| `body.png`                                  | 头 + 发 + 躯干 + 双臂 + 裙摆（**不含腿、不含尾巴**） | 12 帧完全共用，身体绝对稳定 |
| `thigh_L.png` / `shin_L.png` / `foot_L.png` | 左腿：大腿 / 小腿 / 脚（三段分开，关节处稍作重叠）       | 分别旋转 → 膝盖能弯     |
| `thigh_R.png` / `shin_R.png` / `foot_R.png` | 右腿三段                               | 同上，左右独立         |
| `tail.png`                                  | 鲸鱼尾                                | 延迟摆动、摆幅 −40%    |
| `hair_tip.png`                              | 发梢（可选）                             | 延迟摆动            |

有了它，**12 帧全部由我程序生成**：身体是同一张图（逐像素一致），  
腿按你的 12 拍规格旋转，尾巴/头发做延迟 1 帧的次级运动。  
你要的每一条（身高 ≤3%、体轴固定、严格镜像、腿交替可见）**都由构造保证**。

**图层要求**

- 关节处（髋 / 膝 / 踝）**要画重叠**：小腿在大腿下面多画 10~~15px、脚在小腿下面多画 8~~10px，  
  这样旋转时不会露缝
- 每个部件的旋转轴心请标出来（或用一句话告诉我：髋在哪个坐标、膝在哪个坐标、踝在哪个坐标）
- 单格画布 320×400，角色显示高 256px，水平中心 x=160，脚底接地线 y=358
- 透明背景（**不要画棋盘格**）
