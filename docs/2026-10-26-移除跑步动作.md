# 2026-10-26 · 移除「跑步」动作

## 用户要求

> 把跑步的那个动作直接删掉吧先，就是可以备份但是不要出现这个功能了，化繁为简

## 删掉的是什么

原来的「复位」是靠**跑回去**实现的：双击 / 右键 / ⌥⌘H →
宿主用 60fps 定时器把窗口一点点挪回默认位，同时网页播 `run` 剪辑、按方向做水平翻转。
一整套机制包括：

| 位置 | 内容 |
|---|---|
| `desktop/main.swift` | `runTimer/runFrom/runTo/runT0/runDur/runCycleSeconds`、`runHome()`、`lapAnchor()`、`runDuration()`、`startRun()`、`sendToPage()`、`runSelfTest()`、`case "runCycle"`、⌥⌘H → `goHomeOrLap()` |
| `web/pet.js` | `reportRunCycle()`（把跑步周期报给宿主）、`window.petHostEvent` 的 `runStart/runFlip/runEnd` |
| `web/pet-runtime.js` | `ACTION_CLIP.runLeft/runRight`、`facing`、`setFacing()`、`applyFacing()` |
| `web/pet.css` | `transform: scaleX(var(--pet-flip, 1))` 与对应注释 |
| `assets/pet/manifest.json` | `clips.run`（12 帧 / 18fps / `flipForLeft`） |

## 保留了什么

- **归位能力**：双击 / 右键 / ⌥⌘H 仍然归位，但改成**瞬时到位**（`snapHome()`，
  一次 `setFrameOrigin`），不再有位移过程，也没有任何跑步动画。
- **防丢机制**：拖动夹边界（至少留 48×56px 在屏内）、关掉再开回到上次位置、
  换显示器后坐标失效自动回落默认位。
- **素材**：`assets/pet/run.png` 与 `assets/run-12-final/` 原样留在磁盘上，只是不再被清单引用。

## 怎么恢复

代码层面整件事都在一个标签里：

```bash
git show backup-before-remove-run:desktop/main.swift   # 看原来的跑动实现
git diff backup-before-remove-run -- desktop/main.swift web/pet.js web/pet-runtime.js
```

素材没有删，清单里加回 `clips.run`（12 帧 / 2 行 / 18fps / loop 1–12 / `flipForLeft: true`）
再跑 `python3 build-manifest-js.py` 就能重新启用。
