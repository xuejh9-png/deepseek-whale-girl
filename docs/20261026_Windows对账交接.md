# Windows 端用量对账 —— 诊断交接单

> 给接受这份文档的 AI：你在一台 Windows 11 机器上有终端和文件读写权限。
> 下面的任务只有一件事：**查清为什么本地的 Claude 用量统计比接口账单少一半**。
> 只读，不要修改、不要删除任何日志或代码。

---

## 一、已知事实（发起方已经确认过的，不要重复推翻）

同一台机器、同一天（2026-10-26）的三个数字：

| 口径 | 总量 | 调用次数 |
|---|---|---|
| 本地日志统计（网页报告） | 83.28M | 568 |
| 接口供应商后台账单 | 99.4M | 721 |

按平台拆开，差额高度集中：

| 来源 | 本地统计 | 账单 | 差额 |
|---|---|---|---|
| OpenAI / Codex | 66.81M / 538 次 | 68.2M / 563 次 | 1.4M（2%） |
| **Claude** | **16.47M / 30 次** | **32.4M / 190 次** | **15.9M（一半）** |

**结论：16.1M 的缺口里有 15.9M 在 Claude 上，而且调用次数差了 160 次。**
OpenAI 那边只差 2%，属于正常落盘延迟，不用查。

本地统计取的目录是 `%USERPROFILE%\.claude\projects`，解析 `type == "assistant"`
且 `message.usage` 存在的记录，按 `message.id` 去重，token = 四分量之和
（`input_tokens + output_tokens + cache_creation_input_tokens + cache_read_input_tokens`）。

## 二、要回答的五个问题

按顺序查，能早期结束就早期结束：

1. `%USERPROFILE%\.claude\projects` **存在吗**？里面有多少个 `.jsonl`？今天写过的有几个？
2. 今天这些文件里，`type == "assistant"` 且带 `message.usage` 的记录**一共多少条**？
   其中模型名能被 `claude-(opus|sonnet|haiku|数字)` 匹配上的有多少条？
3. Claude 的调用**是不是从这台机器发出去的**？如果是从 CherryStudio / 其他客户端发的，
   它的用量记在哪（`%APPDATA%\CherryStudio` 下的数据库？别的目录？）——这一条决定
   「本地统计天生不全」还是「我们解析漏了」。
4. `%USERPROFILE%\.workbuddy\projects` 存在吗？如果存在，今天有多少条 usage 记录？
5. 如果 1~4 都正常但数字仍对不上，请给出你认为最可能的原因，以及支撑它的证据（文件路径 + 行数/条数）。

## 三、参考脚本（PowerShell，可直接跑；语法报错就按同样逻辑自己重写）

保存为 `diagnose-claude.ps1`，在该文件所在目录执行：

```powershell
$ErrorActionPreference = 'Continue'
$root = Join-Path $env:USERPROFILE '.claude\projects'
Write-Host "=== Claude 日志诊断 ==="
Write-Host "目录: $root"
if (-not (Test-Path $root)) {
    Write-Host "MISSING: 目录不存在 -- Claude 用量没有写到本地"
    return
}

$files = Get-ChildItem -Path $root -Recurse -Filter *.jsonl -File -ErrorAction SilentlyContinue
Write-Host "会话文件总数: $($files.Count)"
$todayStart = (Get-Date).Date
$todayFiles = @($files | Where-Object { $_.LastWriteTime -ge $todayStart })
Write-Host "今天写过: $($todayFiles.Count)"

$tot = 0; $ok = 0; $okTok = 0
$badModel = 0; $noId = 0; $notToday = 0
$models = @{}; $badModels = @{}; $todayFilesDetail = @()

foreach ($f in $files) {
    $hit = 0
    foreach ($line in [System.IO.File]::ReadLines($f.FullName)) {
        if ($line.IndexOf('"usage"') -lt 0) { continue }
        $r = $null
        try { $r = $line | ConvertFrom-Json -ErrorAction Stop } catch { continue }
        if ($null -eq $r.message) { continue }
        $u = $r.message.usage
        if ($null -eq $u) { continue }
        if ($r.type -ne 'assistant') { continue }

        $tot++
        $ts = $null
        try { $ts = [datetimeoffset]::Parse([string]$r.timestamp).LocalDateTime } catch { continue }
        if ($ts.Date -ne $todayStart) { $notToday++; continue }
        $hit++

        $m = [string]$r.message.model
        if ($m -notmatch 'claude-(opus|sonnet|haiku|[0-9])') {
            $badModel++
            if ($badModels.ContainsKey($m)) { $badModels[$m]++ } else { $badModels[$m] = 1 }
            continue
        }

        $c = @(0, 0, 0, 0)
        $i = 0
        foreach ($k in @('input_tokens', 'output_tokens', 'cache_creation_input_tokens', 'cache_read_input_tokens')) {
            $p = $u.PSObject.Properties[$k]
            if ($null -ne $p -and $null -ne $p.Value) { $c[$i] = [int64]$p.Value }
            $i++
        }

        $id = $r.message.id
        if (-not $id) { $id = $r.requestId }
        if (-not $id) { $noId++; continue }

        $t = $c[0] + $c[1] + $c[2] + $c[3]
        $ok++
        $okTok += $t
        if ($models.ContainsKey($m)) { $models[$m]++ } else { $models[$m] = 1 }
    }
    if ($hit -gt 0) { $todayFilesDetail += ("{0} 条  {1}" -f $hit, $f.FullName) }
}

Write-Host ""
Write-Host "--- 今天的 assistant 记录 ---"
Write-Host ("计入统计       {0} 条  {1} token" -f $ok, $okTok)
Write-Host ("模型名不匹配   {0} 条" -f $badModel)
Write-Host ("缺稳定 id      {0} 条" -f $noId)
Write-Host ("不是今天       {0} 条（历史记录，正常）" -f $notToday)
Write-Host ""
Write-Host "--- 计入的调用（按模型）---"
foreach ($k in $models.Keys) { Write-Host ("  {0,4} 次  {1}" -f $models[$k], $k) }
if ($badModels.Count -gt 0) {
    Write-Host ""
    Write-Host "--- 被跳过的模型名（这些本该算进去）---"
    foreach ($k in $badModels.Keys) { Write-Host ("  {0,4} 次  `"{1}`"" -f $badModels[$k], $k) }
}
Write-Host ""
Write-Host "--- 今天写过的文件 ---"
$todayFilesDetail | Select-Object -First 20 | ForEach-Object { Write-Host "  $_" }

Write-Host ""
Write-Host "--- 其他 Claude 数据位置 ---"
$cs = Join-Path $env:APPDATA 'CherryStudio'
Write-Host ("CherryStudio 目录存在: {0}" -f (Test-Path $cs))
if (Test-Path $cs) {
    Get-ChildItem -Path $cs -Recurse -Include *.db, *.sqlite, *.jsonl -File -ErrorAction SilentlyContinue |
        Sort-Object Length -Descending | Select-Object -First 10 |
        ForEach-Object { Write-Host ("  {0,12}  {1}" -f $_.Length, $_.FullName) }
}
$wb = Join-Path $env:USERPROFILE '.workbuddy\projects'
Write-Host ("WorkBuddy 目录存在: {0}" -f (Test-Path $wb))
if (Test-Path $wb) {
    $wf = Get-ChildItem -Path $wb -Recurse -Filter *.jsonl -File -ErrorAction SilentlyContinue
    Write-Host ("  WorkBuddy 会话文件: {0} 个" -f $wf.Count)
}
```
