## 配置与数据含义

- 接口为每人通用；Authorization Bearer Key 决定查询哪把 Key。
- `remaining` 可能是钱包余额或 Key 限额剩余量，不能一律当账号全部资金。
- Windows 读取进程 ANTHROPIC_* 或 Claude settings.json；也支持 PET_USAGE_KEY / PET_USAGE_URL。
- 只自动识别本中转站和本机转发配置；其他供应商的配置不会自动发给本中转站。
- 无开发者 Key 随安装包分发；无 Key 写入日志或响应。Windows 缓存只在内存中，按 Key/地址隔离。
- 请求带明确 User-Agent、8 秒超时、禁止自动跳转；成功缓存 60 秒、失败 20 秒再尝试。
- 断网保留的同 Key 旧值明确标离线，换 Key 清旧值并丢弃旧请求的迟到返回。

## 验证边界

- 状态由本机 Claude Code 日志推断，不会远程读取另一台电脑或 Claude 网页版的工作。
- 未完成状态连续 30 分钟没有业务记录后视为陈旧；日志没写出的活动无法实时感知。
- Windows 11 人工拖动、高 DPI 跨屏、特定显卡透明效果未验证；云端自动化不能代替这些操作。
- Windows 新费用模块使用合成接口验证；真实网络可达性和返回值由用户各自的 Key/网络决定。
- 升级 Mac 源码后需重启 pet_daemon 和宠物窗口；Windows 需安装新版 exe，不会自动更新旧安装。
